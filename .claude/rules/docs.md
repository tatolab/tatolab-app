# Docs

- **Never create a summary doc of what the code already shows.** If it's derivable from the tree,
  read the tree.
- **Docs say what holds now; retired text is deleted, never struck.** When a change retires a
  claim, delete it and repair the sentence around it so it reads as if written that way — no
  `~~strikethrough~~`, no "Superseded …" note, no "(amended …)" narration.
- **`docs/research/` memos are dated evidence** — a memo answers one question as of the day it was
  taken and is never rewritten to match a later tree.
- **`proof/` is evidence, labelled.** Every image says whether it is Live, Live (local proof),
  Linux, or Mock, and a runtime stand-in is named a stand-in. A screenshot of a retired screen
  moves out of the "current" sections of `proof/README.md` or is deleted with the owner's yes.
